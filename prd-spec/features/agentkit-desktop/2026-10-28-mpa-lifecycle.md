# MPA 创建、删除与 Runtime 管理

## 目标与页面位置

在 `codex/work-20261028` 中迁移 Studio 的完整 MPA 创建和删除流程。
新增一级“管理 Runtime”页面，入口位于最左侧原生图标栏的新建会话“+”上方；
选择器仍用于快速切换，设置页 Runtime 目录保留连接入口并提供管理跳转。
管理页按账号、地域和项目列出 Runtime，提供创建、连接、删除与操作历史。
创建不要求先连接已有 Runtime。当前对话及其草稿不因打开管理页丢失。

## 实现选择

创建涉及 IAM、网络、APIG、PostgreSQL、OpenViking、技能空间、Worker、
Runtime、镜像固定和就绪检查；删除涉及实时会话与托管资源归属。
复用 VeADK 1.1.19（对应 Studio #1182）的受维护 Python 编排，避免在 Go
中重写一套不等价的云资源生命周期。Go 宿主通过仅本地 stdin/stdout 的
类型化协议驱动引擎；不开放 HTTP 端口，不从前端接收云账号凭据、命令或 Runtime 服务地址；OpenViking 等业务资源字段按 Studio 合同提交。
发行包随应用携带独立 Python 与锁定依赖，使用方不需安装 Python/VeADK。
开发与构建环境通过项目内 uv.lock 准备依赖，不改全局 Python 环境。

## 创建

- 复用 Studio 的配置检查、名称校验和 CreationTasks；分三步填写名称、
  描述和扩容上限，PostgreSQL，OpenViking/可选 TOS。
- 账号、凭据、owner 与状态目录由 Go 宿主提供；只允许现有支持地域。
  凭据不写入日志、命令行、操作记录和前端状态；OpenViking Key 只在提交时使用。
- 提交前固定请求 UUID，保存无密钥草稿；结果未知时按原身份查询恢复。
  后台任务显式取消、状态轮询、失败诊断、同身份重试、终态后新建均可用。
- 成功后刷新目录，可连接新 Runtime。取消保留已创建资源，不声称回滚。

## 删除

- 对所选 Runtime 重新读取身份、部署标签、MPA 实例与管理权限。
- 预览包含会话总数/活动数/空闲数、阻塞原因、清理计划、保留共享资源。
  活动会话、部署/镜像操作或无法验证的归属阻止删除。
- 确认绑定预览指纹、Runtime、账号与地域；实际删除前重读并再次验证。
  依次清理空闲会话、专属 Worker/技能空间、Runtime，并记录实际阶段。
  共享网络、APIG、数据库及其他共享资源按 Studio 规则保留。
- 删除异步执行并持久化结果；禁止自动重复写入。异常保留失败/未知状态，
  通过云端状态核对后才能继续。被删对象为当前连接时清理连接与会话投影。Go 宿主独立于页面核对已接受的删除，完成时按云账号 epoch、地域和 Runtime ID 原子清理目标，并通知原生壳层；用户切换的新连接不受影响。

## 隔离、生命周期与验证

引擎按云账号/主体与登录 epoch 隔离，任务历史按验证后的主体隔离；
退出或切换账号后拒绝迟到响应。应用退出时关闭引擎并回收子进程；
保留可恢复意图。页面关闭仅停止 UI 轮询，不等于取消创建。

测试覆盖引擎协议与凭据边界、创建幂等/恢复/取消、删除预览与重新验证、
活动会话/共享资源保护、未知结果及账号切换；全部测试使用隔离模拟服务。
真实云创建/删除不属于自动验证。完成前检查中英文、键盘/IME、窄窗口、
加载/空/错误状态、原有聊天和 Runtime 切换、Python 引擎随包可用、Go/前端
检查与桌面构建。完成后补充实际验证记录和剩余限制。

引用扫描 `list_runtimes` 达到原 25 秒预算；不是创建引擎缺失。原实现把全部未知
预检查异常折叠为 lifecycleUnavailable，因此界面错误地提示“创建引擎不可用”。

修复范围：

- 每次检查使用独立 DeletionCloud，在同一不可变凭据快照下验证一次云身份。
  只读预检查复用完整目录快照，避免 target 与 OwnedResourceCleanup 重复全量扫描。
- 受理检查、执行检查均使用新云客户端；真正清理专属资源前显式清掉目录快照，
  保留原 OwnedResourceCleanup 的完整引用重读和资源归属验证，不绕过共享资源保护。
- 预检查预算为 60 秒，Go 预检查/受理请求预算为 90 秒；删除执行仍有 180 秒边界。
- 预检查分阶段记录 checking、runtime_sessions、registry、references、worker_template、
  skill_space 等位置。安全诊断经 Python → Go SafeError → 前端保留阶段、操作、
  分类、异常类型、HTTP 状态、Request ID、白名单归属原因、主机名和脱敏源码位置。
  不记录原始异常消息、响应正文、URL 凭据或完整 Runtime 环境。
- 删除页展示可复制错误详情；预检查失败时没有确认删除入口。受理前明确拒绝不
  标成已执行；写入后失败仍保留未知状态，禁止自动重发破坏性请求。
- 安全诊断写在主体隔离的本地任务库，最多保留 100 条，不把预检查失败当成已受理
  删除任务。真正的引擎启动失败使用“资源管理引擎不可用”，与 API/网络错误区分。
