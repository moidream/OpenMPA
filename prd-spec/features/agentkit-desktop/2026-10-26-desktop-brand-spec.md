# 桌面品牌与标题栏对齐

范围：当前桌面客户端的标题栏分割线、原生快捷栏首页标志、应用图标与可编辑品牌源文件。基线为 `8091324942b86789ed0da7facbee855145d933b0` 上的当前客户端工作区；保留已有工作。按用户提出的设计、修复及编译预览授权实施，继续 mstack / spec-driven-dev-loop；不提交、不发布、不修改 Runtime 或 Worker。

## B1 标题栏

44px 原生标题栏保持画面的第一个区域。1×16px 分割线中心对齐标题栏与展开折叠按钮；显式覆盖 MyGo Divider 自带的 AlignSelf(Stretch)。展开、折叠以及 640/760/1200px 窗口均满足要求。交通灯、产品名称、折叠按钮、当前位置与右侧操作的顺序不变。

## B2 品牌标志

以开口的 O 圆环表示 OpenMPA，右上方一个独立节点表现会话与协作。几何构造为单环与单节点；深灰 `#303832` 与柔和绿 `#739873`，保持扁平、静态、无装饰动画。原生快捷栏使用单色版本及已有 36px 点击区域、首页语义、焦点与提示。助手角色插画继续使用现有资源。

## B3 应用图标与源文件

Dock / Finder 使用透明画布内的浅色圆角底板，中心放置同源彩色标志。提供可编辑 SVG、1024px PNG 与含标志和 OpenMPA 名称的 SVG；原生标志直接读取嵌入的 SVG，避免低分辨率位图。通过 mygo.json 的顶层 icon 字段接入标准 PNG→ICNS 打包，保持 app bundle 标识与版本。16/32/64px 缩略图保持开口及节点辨识。
